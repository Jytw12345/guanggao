🔄 核心工作流程总览

新建预约 → 分配人员 → 开始施工 → 施工中/暂停/恢复 → 完成施工（自动考勤 + 分成比例）→ 验收 → 审核

系统围绕项目生命周期设计，从预约创建到最终审核，每个环节都有明确的操作和数据记录。

💡 流程特点

系统支持灵活的人员变动管理（加人/减人），自动计算已移除人员的工时；支持多次暂停/恢复，暂停期间不计入工时；完工时自动汇总所有参与人员的工时记录。

📊 项目状态流转

预约中 → 施工中 ↔ 已暂停 → 已完工 → 已验收 → 已审核 ↓ ↓ 已取消 已延期

📌 状态胶囊显示次数

当项目当前处于「已延期」或「已暂停」时，卡片右上角与详情页的状态胶囊会一并显示累计次数，例如「已延期 2次」「已暂停 1次」（仅当前处于该状态才显示次数）。处于其它状态、但历史上有过延期 / 暂停的项目，仍通过独立的「📅 已改期」等标记体现，不重复计数——既保留次数信息，又避免与状态文字双标。

状态流转规则

  • 预约中 → 施工中：点击"开始施工"，必须先分配安装人员
  • 施工中 ↔ 已暂停：可多次暂停和恢复，暂停期间不计入工时
  • 施工中/已暂停 → 已延期：点击「项目延期」按钮（需填原因）改期，系统也会针对超时未完工提示延期
  • 任意状态 → 已取消：需填写取消原因，取消后只读
  • 施工中/已暂停/已延期 → 已完工：点"完成施工"后系统按在场时段自动生成考勤工时（无需手填），并拖动分成比例确认
  • 已完工 → 已验收 → 已审核：逐级审批，不可逆

📝 项目预约流程

第一步：新建项目预约

1.1 填写项目基本信息

项目名称、客户名称、联系电话、门店、安装地址

1.2 设置预约时间（只填施工时间段）

选择日期、开始时间与结束时间即可——预约时不再填写「预计总工时」和「施工人数」。保存时系统自动按 各段时长之和 × 已分配施工人数 推算出预计总工时（人·小时，仅作考勤与排班参考，不计入工资）。

快捷时间：提供「2小时 / 上午 / 下午 / 全天」一键填入开始与结束时间——上午 08:00–12:00、下午 13:00–18:00、全天 08:00–18:00、"2小时"以当前开始时间为准往后推 2 小时。

1.3 分配施工人员

选择内部施工人员或填写外协人员（外协人员不参与时间冲突检测）

1.4 保存项目

点击"保存"完成创建，项目进入"预约中"状态

💡 快捷操作

当选择今天日期时，开始时间自动根据当前系统时间向上取整，结束时间默认往后推2小时

人员冲突检测

分配人员时系统会自动检测时间冲突，如果该人员在此时间段已被分配到其他项目，会弹出提示。您可以选择是否继续分配。

💡 冲突检测覆盖范围（持续完善中）

  • 分配安装人员：个人日程 / 已审批请假 / 其它未完工项目时段重叠时，分别硬拦截或软提示确认。
  • 发起 / 改期维修单：选完维修人员后，自动检测该维修时段是否与其请假、个人日程、其它项目撞车，撞车弹「维修人员冲突」确认框（可仍提交）。
  • 发起返工：沿用原项目派工，生成前同样按新返工时段检测冲突，撞车弹「返工人员冲突」确认框。
  • 开工冲突：已改为按绝对时段重叠判断——上周一直"施工中"未点完工的老项目，只要与今天新工不在同一时段，不再误拦。
  • 请假口径：冲突拦截与可用工时计算只认"已审批"请假；待审批请假不再硬拦派工、也不扣减可用工时（若最终驳回则无影响）。
  • 请假与工时无关：包活制下工资 = 包活分成，请假不扣工时、不影响包活分成；表单只提示「请假时长：N 天（08:00–18:00，仅作考勤参考）」，请假的工时折算仅用于排期占用与考勤告警阈值。

📅 修改预约时间留痕（已改期）

预约中的项目，通过编辑项目、时间轴拖拽、或快捷改期修改过预约时间后，系统会永久保留最初排期并显示「📅 已改期」标记：

  • 卡片：紫色「📅 已改期」徽标；
  • 详情页：施工记录区显示「已改期 · 原预约 + 原时间」紫色卡片，一眼看到最早约的几号几时；
  • 时间轴：任务条上显示「📅 已改期」。

💡 与「延期」的区别

普通改期只是静默改时间并留痕，状态仍是「预约中」；「延期」是带原因的另一套流程，状态变为「已延期」并保留原时间 + 原因。已延期状态不再叠加「已改期」徽标，避免重复。

📌 快速修改：超期项目自动调到今天

通过卡片「快速修改」打开预约时间弹窗时，若原预约日期早于今天（如昨天排的活一直没动、已超期），弹窗会自动把日期默认改成今天、时间仍保留原预约时段（若原时段已过时，现有逻辑会自动往后顺延到可用时段）。这样超期项目点开不会还显示过去的日期、也不会等到保存时才提示。

📅 跨天施工预约

当一个项目一天干不完、需要分多天施工时（例如：第一天 7:00–20:00、第二天 8:00–16:00，中间留足休息 / 睡觉时间），使用「跨天施工」功能。系统按「每日独立施工时段」建模，而不是把时间连续拉长到跨午夜——这样既符合真实的作息，也不会在工时与预警上产生误判。

什么时候用跨天

  • 单日施工窗口（如 8:00–18:00）装不完，需顺延到第二天上午 / 下午继续；
  • 多日连续作业，但每天都有独立的开工、收工时间，夜里不施工；
  • 工期分散在多个日期（如 D1、D3、D5 各干一段），也可逐天添加。

📌 与「夜间 / 跨午夜」的区别

「跨天」是多天各一段（中间有休息），不是"从今晚干到明天凌晨"。系统对开工后跨午夜仍在施工中的项目会判定为「🌙 跨夜未完工」（疑似忘点完工）；而正常的跨天施工是每天各自收工、第二天再开工，不会触发该预警。

如何设置跨天预约

1. 填写第一天

在「新建 / 编辑项目」弹窗，按正常方式填好第 1 天的日期、开始时间、结束时间（即主预约时间）。系统会自动算出这一天的现场占用时长。

2. 点击「➕ 添加一天（跨天施工）」

在预约时间区域下方，点击该按钮新增第 2 天的分段行。新行默认填为下一天 08:00–18:00，可手动改为实际日期与时段（如第二天 8:00–16:00）。

3. 继续添加更多天

按需重复点「➕ 添加一天」，每行相互独立、日期自动顺延；某天不干了可点该行右侧的「✕」删除。每行都显示「第 N 天」标签 + 日期 + 开始 / 结束时间。

4. 查看总施工时长

表单实时按所有分段时长求和显示「总施工时长」（如「2天 共31小时」）。预约时不再填写总工时与人数，保存时系统按 总时长 × 已分配人数 自动推算预计总工时（人·小时，仅作考勤参考）。

5. 保存

点击「保存」后，项目按多段日程入库：开始时间取首段起、结束时间取末段止，分段明细存入「施工时段」。

跨天在各视图的显示

  • 时间轴 / 日历：按当前选中的日期逐日裁剪，只显示该项目当天那段施工窗口（不会把多天拼成 24h+ 长条）；任务条带「📅 跨天 N 天」徽标；禁止直接拖拽改期（拖动会破坏分段数据），要调整请回「编辑项目 / 修改预约」弹窗的跨天分段里改。
  • 项目卡片：标题区带「📅 跨天 N 天」徽标；"预约时长"显示真实施工工时（各段时长之和，不含夜间睡觉）；开工后卡片时间线按 workSessions 逐段列出每天实际施工时段并给出合计；卡片预约时间显示为「首段起 ~ 末段止（带日期）」。
  • 项目进度跟踪（施工管理页）：跨天项目每天都会出现在对应日期；显示「📅 第 N 天 / 共 N 天」徽标与「第 N 天 · 当天时间段」（如「第 2 天 · 08:00~18:00」），一眼看清当天该干什么。
  • 提成统计：跨天项目的考勤工时优先取系统按在场时段自动生成的记录；施工管理页还会列出跨天项目工时明细——各分段范围 + 实际 / 计划工时，避免只看汇总数字被误导。

注意事项

  • 每一天的结束时间必须晚于开始时间，否则保存时会提示「每段结束时间需晚于开始时间」。
  • 跨天施工时，预计总工时由系统按 各段时长之和 × 已分配人数 自动推算（人·小时，仅作考勤参考）；预约表单不再提供手填工时与人数。
  • 跨天分段与普通过夜一样，一旦开工即锁定：已开工 / 终态项目的预约时间、分段数据不可再改（改期请走「延期」流程）。
  • 分段数据向后兼容旧项目：没设分段的旧单天项目，系统自动按原预约起止时间合成单段，不受影响。
  • 「✏️ 修改预约」同样支持跨天：在卡片弹窗点「✏️ 修改预约」或「✏️ 编辑」打开的表单，也能查看 / 增删跨天分段；保存时保留全部分段，不会把多日项目误存成单日、丢失数据。
  • 🟠 跨天提前完工会被拦截提示：如果还没干到预约末天就点「完工」，表单顶部弹橙色警告——说明应每天结束点暂停、次日点恢复、最后一天再完工，点「确认完工」时还会二次确认，避免误点。确实要提前收工，确认提示后继续即可（考勤工时由系统按在场时段自动生成，仅供参考）。
  • 「📅 跨天 N 天」徽标仅在未完工项目显示：项目进入已完工 / 已验收等终态后，卡片不再挂跨天徽标（已完工的跨天历史无需再提示）。

⚙️ 施工管理流程

第一步：进入施工管理

从项目预约卡片点击「施工管理」按钮，进入项目详细管理页面。

第二步：分配安装人员

2.1 添加人员

在"安装人员分配"区域，点击"+"按钮选择施工人员，系统自动记录分配时间

2.2 移除人员

点击人员旁边的"×"按钮移除，系统自动计算该人员从开工到移除的工时并记录

💡 自动工时计算

移除人员时，系统自动计算：工时 = 总施工时间 / 施工人数（平均分配），并自动创建工人工时记录

第三步：关注工时异常

施工管理页顶部「今日需关注」会自动识别预约工时与可用施工窗口不匹配的项目。例如：

  • 预约总工时 50h，但只安排了 2 人、施工窗口仅 10h → 人均需 25h，远大于当天可用时间；
  • 施工窗口 08:00–18:00（10h），2 人理论上最多完成 20 人·小时，若预约工时超过此数即会触发提醒。

⚠️ 系统会给出哪些提示

列表顶部黄色/红色警示条：汇总所有异常项目，说明「X 人 × Y 小时窗口需人均 Z 小时」，并给出建议——增加人手、缩短预约工时、拆分多天或延长施工时间。

协作项目卡片：多人项目下方直接标注「⚠ 人均 Xh，但当天仅 Yh 可用」。

项目进度跟踪：异常项目标题旁出现「工时异常」标签；展开详情可见「工时可行性」一行，列明人均需工时、当天可用窗口和建议。

日历时间线 / 施工甘特：异常项目的时间条会以橙/红描边高亮，并带上「⚠ 工时异常」标签，与进度跟踪提示一致。

新建 / 编辑 / 修改预约保存时：若人均工时 > 可用窗口，会弹窗提示「工时严重异常 / 工时可能不合理」，可取消修改或继续保存。

看到此类提醒时，优先检查：人数是否太少、总工时是否填错、施工时间段是否过短、是否应拆成跨天施工。

第四步：开始施工

3.1 检查人员分配

系统自动检查是否已分配安装人员，未分配时提示先分配人员

3.2 记录开工时间

点击"开始施工"按钮，系统记录当前时间为开工时间，项目状态变为"施工中"

第四步：施工过程管理

4.1 暂停施工

点击"暂停施工"按钮，填写暂停原因（可选，支持快速选择或手动输入），系统记录暂停时间，暂停期间不计入工时

4.2 恢复施工

点击"恢复施工"按钮，系统记录恢复时间，从当前时间重新开始计时

4.3 项目延期

点击"项目延期"按钮，设置新预约时间（默认8:00）和延期原因，系统记录延期历史

💡 进度条显示规则

包活制下进度条按项目状态显示，不再按工时折算：

施工中：琥珀色进度条（50%）；已暂停：橙色进度条（40%，暂停期间不再增加）；已延期：红色进度条（30%），提示项目超期；已完工 / 已验收 / 已审核 / 已取消：绿色进度条，固定显示 100%。

第五步：完成施工

5.1 打开完工表单

点击"完成施工"按钮，系统自动汇总所有参与人员（包括已移除人员）

5.2 自动考勤（无需手填工时）

包活制下，完工表单不再要求手动填写工时。系统会按每位工人的实际在场时段（依据人员变动历史与暂停时段）自动生成考勤工时，仅供考勤参考、不计入工资；表单中以只读方式预览每人工时与合计。如需纠错，可在项目详情页删除对应考勤记录。

5.3 确认分成（比例 / 金额）

完工时在汇总比例条上拖动分隔点，调整各安装人员的分成占比——比例为整数百分比，拖动按 1% 吸附，合计自动归一到 100%；也可切换到「按金额分配」，直接拖金额或在输入框手填每人多少钱（合计需等于扣除外协后的剩余池）。有外协人员时，先在「外协固定工钱」区为每名外协填固定金额（先从分成池扣除，剩余再按比例分）。系统实时显示每人分成金额。外协金额忘填将按 ¥0 结算——未填时该行输入框红框提示，点「确认完工」会弹窗提醒（可取消回弹窗补填）。确认后项目状态变为"已完工"，分成方式一并写入云端。

💡 分成与考勤分离

完工表单会显示所有曾经参与过该项目的工人（当前分配的正常显示，已移除的标注"已移除"），并列出：

  • 每人自动考勤工时（只读预览，系统按在场时段计算）；
  • 一条彩色分成条，拖动分隔点即可调整相邻两人的占比（1% 整数刻度，合计自动补到 100%），或切换「按金额分配」直接定钱数，下方显示每人分成金额；
  • 有外协人员时，比例条下方列外协固定工钱（每名外协填固定金额，先从分成池扣除，剩余再按比例分）；
  • 合计施工工时仅作考勤参考，不影响客户费用与工人分成。

📌 考勤记录的操作时机

包活制下不再有手动填写工时入口：施工管理详情页的「施工人员工时（考勤记录）」仅展示系统自动生成的考勤工时，只保留「删除」按钮用于纠错（需删除工时权限），不再提供新增 / 修改。预约中、施工中、已完工等状态下都不用手填工时。

考勤记录有误如何更正？若某条考勤工时明显不准（如忘点完工导致跨夜时长被计入），拥有「删除工时记录」权限的成员可在施工详情页删除该记录；系统会在删除后重新汇总合计工时。包活制下考勤不影响工资，更正以"删除多余记录"为主，不必逐段修改。

取消项目

⚠️ 不可逆操作

⏱️ 工时管理流程

工时计算规则

实际工时（考勤） = 所有工人考勤工时记录之和（均由系统按在场时段自动生成）

工时记录方式

  • 自动考勤：完工时系统按每位工人的实际在场时段（人员变动历史 + 暂停时段）自动生成考勤工时，无需手动填写；
  • 删除纠错：考勤记录有误时，拥有删除权限的成员可在项目详情页删除多余记录，系统重新汇总合计；
  • 外协考勤：外协人员的在场时段同样自动计入考勤，以紫色标识；
  • 包活制下工时仅供参考：考勤工时不计入工资，工资按"工费的一半"在工人间分成。

工时等级与作业类型（已简化）

包活制下，工时不再按"等级 / 作业类型"分级计费，手动填写也已取消（工时由系统按在场时段自动生成）。因此：

  • 项目详情的施工人员工时（考勤记录）表不再展示「作业类型」「等级」两列——它们恒为默认值，没有信息量；
  • 所有考勤记录默认按「中级 / 地面施工」入库，仅作考勤存档，不参与任何计算；
  • 历史数据里的等级与类型仍完整保留在 Excel 导出中（便于追溯），但界面上不再展示。

工时差异（已取消）

系统不再显示工时差异（实际 − 预计）。包活制下施工时长不参与结算、不作为考核点，差异数值既不影响工资也不影响分成，展示出来只会误导。原先的「预计工时 / 外协工时 / 差异」三项已从项目详情移除，只保留「实际工时（考勤）」作为出勤凭证。

系统自动工时（参考工时）

考勤工时由系统按每位工人的实际在场时段自动生成（人员变动历史 + 暂停时段截断），作为参考基准用于排班与劳勤核对。

  • 系统自动工时与登记的考勤工时均仅供核对参考，不进入工资结算；包活制下工资以"工费的一半"分成，与工时脱钩；
  • 「提成统计」页与导出报表已改为按人 / 按天统计提成，不再汇总初 / 中 / 高 / 特级工时；考勤数据仍可在项目详情页的「工人工时统计」区块查看。

预计工时自动计算

💡 全自动推算（预约只填施工时间段）

预约表单不再提供「预计总工时 / 施工人数」输入。保存时系统自动按 各段时长之和 × 已分配施工人数 推算出预计总工时并保存（人·小时口径）。

  • 新建项目：尚未分配人员时人数按 1 计，即预计总工时 = 总施工时长；分配人员后可按需重新保存一次，让总工时跟随人数刷新。
  • 编辑 / 快速修改：改了施工起止时间段后，预计总工时会按上式自动跟随重算。
  • 无「修改预约工时」权限的账号，保存时强制保持原值，不会被自动推算覆盖。

计算公式：预计总工时 = 总施工时长 × 已分配人数。例如：施工时间 2 小时、已分配 2 人，预计总工时 = 4 小时。该值仅用于考勤核对与排班，不影响包活分成。

💰 包活制（承包结算）

系统已从「工时制」切换为「包活制」：工人工资不再按"工时 × 等级单价"计算，而是按工费的一半在项目施工人员之间分成。工时仅保留作为考勤参考，不再计入工资。

两种包活方式

方式工费计算公式说明
包工工费 = 工程金额 − 成本扣项纯人工。「成本扣项」用于扣除吊车、运费等现场代付成本（例：包工 1100 = 工费 350 + 吊车 800 → 分成池按 350÷2 = 175）；不填扣项时工费即客户应付总额。
包工包料工费 = 工程金额 − 材料费含材料。需单列"材料费"，工费为客户应付总额扣除材料成本后的纯人工费。

📌 工费取值优先级

若项目已存过工费（laborFee > 0）则直接采用存储值；否则按上述公式实时派生。新建项目时工程金额必填，否则无法保存。

新建 / 编辑项目时填写包活信息

1. 选择「包活方式」

在预约表单中单选包工或包工包料。两种方式都显示扣项输入框：包工包料叫"材料费"，包工叫"成本扣项"（吊车 / 运费等现场代付成本）。

2. 填写「工程金额」

客户应付总额（必填）。表单实时显示派生工费与工人分成池（工费 ÷ 2）。

3. 填写「施工内容」

在原有施工内容字段中描述具体作业范围（围栏杆、道旗、广告安装等）。

4. 填写「材料费 / 成本扣项」（选填）

包工包料填材料成本；包工填吊车、运费等现场代付成本。系统据此从工程金额中扣除得出纯工费，扣项不参与工人分成。

工人分成（工费的一半）

工人分成池 = 工费 ÷ 2

例：一个活工费 300 元、2 人施工，两人合计分得 150 元。分配方式有三种，在项目详情的「分成」面板中设置：

分配方式规则适用场景
平均分（avg）分成池按参与工人均摊，尾差补到最后一人多人出力相当
自定义比例（custom）内部安装工人汇总到一条彩色比例条，拖动条上分隔点即可调整相邻两人占比；比例为整数百分比（1% 刻度，不显示小数），拖动时按 1% 吸附、松手自动归一化，合计恒等于 100%（不会出现 99.9%），金额实时计算。外协人员不进比例条，按固定金额先从分成池扣除有人出工多 / 带班
按金额分配（custom_amount）直接拖动金额或在图例输入框里手填金额（¥），比例由金额自动换算；金额合计需等于扣除外协后的剩余池，尾差补最后一人。适合「这次给张三 200、李四 150」这种直接定钱数的场景已谈好各自拿多少

三种方式都遵循同一前提：外协固定工钱先从分成池扣除，剩下的钱才在安装工人之间分。

分成面板（项目详情内）

  • 详情页展示：包活方式 / 工程金额 / 工费 / 工人分成池，以及一条彩色比例条（每段显示工人姓氏与占比，下方用同色圆点列出姓名与金额）；
  • 权限：经理 / 店长可拖动比例条分隔点、切换分配模式并保存；工人只读；
  • 自定义比例：比例按 1% 整数刻度显示与拖动（不出现小数），系统自动归一化，合计恒等于 100%（3 人默认均分为 33% / 33% / 34%），不会因拖动出现 99.9%；
  • 按金额分配：每段直接显示金额，可在图例输入框手填，也可拖动条上分隔点（按 1 元调整）；所有金额合计需等于扣除外协后的剩余池，否则「保存分成」时会提示差额；
  • 保存时机：修改比例 / 模式仅改内存，需点「保存分成」才写入云端（避免误改）；
  • 项目卡片：显示包活方式徽标、工程金额与分成池，一眼看清承包概况。

提成统计与导出（原「工时统计」页）

底部导航的「💰 提成统计」页已从工时口径切换为提成口径，按周期（月 / 季 / 年）+ 门店 + 人员 + 状态筛选：

  • 统计口径：完工后才计入——只有已完工 / 已验收 / 已审核的项目才计入提成、金额与分成池合计；施工中、已暂停、已延期、预约中以及已取消的项目一律不提前计入，完工后自动计入（已取消的项目永不计入）；此口径同时作用于提成统计页、施工人员卡片的「累计 / 本月提成」与 Excel 导出报表；
  • 顶部卡片：参与施工人数、本期提成合计、本期工程金额、工人分成池（工费÷2）、外协人数；
  • 人员提成：每位施工人员的本月提成（¥）、施工天数、请假 / 轮休天数、参与项目数，并附本月提成日历——每天的格子直接显示当天到手提成（¥）；
  • 项目提成明细：逐项目列出工程金额、工费与每位工人的提成（¥），底部给出合计；
  • 跨天项目的提成拆分：每人的项目提成总额 = 分成池 × 比例（与工时脱钩），再按该工人每日在场工时占比摊到各天；无考勤数据时平均摊到各施工分段日；
  • 外协人员：不进比例条、不参与比例分配——在「外协固定工钱」区为每名外协填固定金额，该金额先从分成池扣除，剩余部分再由安装人员按平均 / 自定义比例分配（两种模式均适用）；固定金额合计不得超过分成池，外协提成正常计入统计与导出；忘填将按 ¥0 结算（该外协本次不参与分成）——未填时输入框红框提示、标题徽标显示「N 名未填」，点「保存分成」或「确认完工」时会弹窗再确认一次（确认后仍可按 ¥0 保存；明确填 0 属合法值，不触发提醒）；
  • Excel 导出：「导出统计数据」生成提成统计报表——统计概览（人数 / 工程金额 / 工费 / 分成池 / 提成合计）、「人员提成」、「每日提成明细」（按人 × 按天 × 项目）、「项目提成明细」工作表，并为每位工人单独生成提成核算表（含包活提成明细、每日提成日历与工资核算：提成工资 + 补贴 − 扣款 = 实发）；
  • 项目人员提成明细（导出表）：按「项目 × 施工人员」逐行列示——日期、预约开工、店面、项目名称、施工内容 / 注意事项、效果图（完成效果图首张缩略图直接内嵌到单元格，无图时显示张数文字）、工程金额、工费金额、施工人员、分配比例、个人提成，底部给出个人提成合计；无分配工人的项目也会列示（施工人员显示「—」），方便核对施工内容与效果图；
  • 施工人员卡片：人员列表卡片显示「累计提成 / 本月提成（¥）」，不再显示累计工时；
  • 店面统计：门店汇总表的工时列已改为工程金额 / 工费（不再显示工人提成）；点门店「查看」可在项目卡片中查看每个项目的工程金额与工费；
  • 考勤工时（初 / 中 / 高 / 特级）不再进入统计与导出，仅在项目详情页作考勤参考。

老项目（无包活字段）默认按"包工"处理，工程金额为 0 时不参与分成聚合。新字段需先在 Supabase 执行对应迁移后才会持久化（详见部署说明）。

2. 验收项检查

安装位置准确、安装牢固、外观整洁等检查项

审核流程

1. 审核考勤

查看项目考勤工时记录（包活制下仅作参考，不计入工资）

2. 审核验收结果

确认验收结论和检查项

3. 提交审核

点击"审核项目"，项目状态变为"已审核"，记录审核时间

取消审核

已审核项目如核对有误，可在审核/验收页「取消审核」，退回为「已完工」状态重新走验收流程。

📌 验收信息的显示时机

「验收信息」区块只在项目进入终态后显示：已完工（显示「填写验收信息」按钮）、已验收 / 已审核（显示验收记录与「修改验收」）。施工中 / 预约中 / 已暂停 / 已延期时不显示，避免提前误点。已取消项目仅在有验收记录时显示。

⚠️ 开工锁定与终态锁定

① 开工即锁定：项目一旦开始施工（进入「施工中」「已暂停」，或曾经开工过），其预约时间与预约工时（预计工时）立即锁定，即使拥有「修改所有项目预约时间 / 预约工时」权限也无法再改。因为预约时间与预约工时在开工那一刻就成为考核基准（用于对比实际工时、统计准点率），事后修改会让统计失真。

需要改期怎么办？使用施工管理页的「📅 延期」功能——它会要求填写延期原因，并完整保留原预约时间与延期记录，既能改期又不破坏可追溯性。实际施工耗时由系统按在场时段自动计入考勤，无需手动登记。

② 终态锁定：项目进入已完工 / 已验收 / 已审核后同样锁定，编辑页相关字段变为只读。取消审核退回「已完工」后仍属终态保护，预约时间与工时保持锁定。

不受影响的情况：「预约中」的项目，以及由「预约中」延期而来（尚未开过工）的项目，仍可正常修改预约时间与工时。项目的名称、客户、地址、备注等基本信息在开工后也仍可编辑（需「编辑项目」权限），只有预约时间与预约工时被锁。

🔄 返工管理

原项目已完工 / 验收 / 审核后，因质量等问题需要再次施工时，使用「返工」功能。返工会生成可独立排期、独立核算的施工任务，并自动关联回原项目，便于追溯。

发起返工

在终态项目（已完工 / 已验收 / 已审核）的施工管理页，点击「🔄 返工」按钮，弹出返工表单。

填写返工表单

预约时间

选择返工日期、开始与结束时间段（提供快捷时间段按钮），即再次施工的排期。返工不一定立即施工，可预约到未来的某天。

返工内容（必填）

填写需要返工的具体内容，作为独立字段记录；施工人员打开返工单可清楚看到要做什么。

注意事项

可填写返工时的特别注意事项。

人数与工时（自动计算）

无需手填。施工人数 = 已分配工人数，预计总工时 = 总施工时长 × 人数，保存时自动派生，仅用于考勤核对与排班，不影响包活分成。

返工收费（默认免费）

返工默认是免费返工（工程金额 ¥0，不产生客户费用与工人分成）。若这次要向客户收费，切换为「💵 计费返工」并填写包活信息：

  • 包工（仅出人工费）：工费 = 工程金额，分成池 = 工费 ÷ 2。
  • 包工包料：工费 = 工程金额 − 材料费，分成池 = 工费 ÷ 2。

计费返工的工程金额为必填（未填会提示），填完后与原项目一样走「完工 → 分比例 / 按金额分配」结算；免费返工只记考勤工时，无分成。

两种返工模式（单选）

模式说明对原项目的影响
🆕 新建返工单生成一条独立的新预约（状态=预约中），与原项目并存不变；原项目详情会列出「🔄 返工单」及返工内容摘要，并聚合显示返工工时
♻️ 转回老单重做把原项目本身改回「预约中」并重填时间 / 返工内容 / 工时历史工时保留、项目名不变，重新走施工→完工流程

关联与追溯

  • 返工单详情页显示「返工源自：<原项目名称>」，可点击跳转回原项目。
  • 原项目详情页显示「🔄 返工 N 次」徽标，并在「返工单」区块列出每条返工单（名称 / 状态 / 工时 / 返工内容摘要）。

返工收费方式

包活制下返工与正常项目同一套结算口径：工资 = 工费的一半按分成方式分配，工时只作考勤，不计入工资。返工单详情页底部展示本次返工的收费摘要：

  • 🆓 免费返工（默认）：工程金额 ¥0，无客户费用、无工人分成，只记录考勤工时。
  • 💵 计费返工：显示包活方式（包工 / 包工包料）、工程金额、工费与工人分成池，与原项目一样可分比例或按金额分配（仅经理 / 店长可改）。

该摘要仅有「查看全局统计」权限者可见；施工人员打开返工单看不到金额信息。

🔧 维修单

原项目已完工 / 验收 / 审核后，因客户报修需要上门维修时，使用「维修单」。维修单挂在原项目上（作为待办），不会改写原项目的预约时间，因此不会污染已完工原单在时间轴、人员安排与日历里的展示。

同一项目可多次维修

维修单以列表形式挂在原项目上，支持同一项目多次发起（如修了又坏）。每条维修单有独立编号（#1、#2…）、独立预约维修时间与状态。详情页「维修单」区块会列出全部维修单，每条可单独完成 / 改期 / 删除；点击「🔄 再发起维修单」可新增一条待维修单。

发起维修单：选收费方式

发起时需选择本次维修收不收费（与返工一致，不再填「预计工时」）：

  • 🆓 免费维修：保修期内上门，不产生客户费用与工人分成。
  • 💵 付费维修：需填写工程金额（必填），并选择包活方式——包工（仅出人工费）时工费 = 工程金额；包工包料时工费 = 工程金额 − 材料费。表单实时显示派生的工费与工人分成池（工费 ÷ 2）。

维修单无结束时间，系统按预约时间起 2 小时作为冲突检测窗口，撞车时会弹「维修人员冲突」确认。

完成维修

完成维修时弹出行内表单：勾选参与维修的人员 + 填写整单实际用时（默认 2 小时，仅作考勤参考，不影响分成）。

  • 免费维修：只写考勤工时，无分成金额。
  • 付费维修：表单实时显示「每人 ¥X」预览——分成池（工费 ÷ 2）在勾选人员中自动均分，尾差补最后一人；确认后写入提成，计入提成统计与工资页（按完成日期入账）。

此逻辑与返工一致：只有收费性质的维修才会产生分成，免费维修只在考勤侧体现。

进入待处理提醒

状态为「待维修」的维修单会出现在首页「待处理提醒」汇总区（超预约未修显红色），也出现在时间轴、人员安排与日历的对应日期，便于提前安排。

🔔 预警与待处理提醒

📌 仅总经理可设置

提醒标准为全局统一配置，由总经理在「我的 → 管理员设置 → 提醒设置」中调整，对全体成员的提醒标准一致。其他角色在界面上看不到该入口。

一、项目类预警

项目预约列表与施工详情卡片会针对以下异常自动标红 / 高亮并置顶；同时首页「施工概览」顶部的智能提醒会跨日聚合显示「忘记施工 / 逾期未开工」——即便该项目预约在昨天、今天没有任何施工段，也会在今日概览里出现，提醒尽快处理：

预警触发条件表现
⏰ 逾期未开工预约时间已过仍未开工（含历史任何日期，但预约日尚未跨到次日）琥珀色徽标 + 高亮，概览顶部汇总
🚨 忘记施工逾期未开工且预约日期已跨到次日或更久（如昨天排的活今天还没干），属典型"忘排 / 忘施工"红色徽标 + 高亮，优先级高于普通逾期未开工，概览顶部红色置顶
🌙 跨夜未完工开工后跨午夜仍在施工中（不可能整夜施工，必为忘点完工）红色徽标 + 强红高亮
⚠️ 连续施工超时连续施工超过总经理设定的阈值（默认 12 小时；中途暂停不计入）橙色徽标
🌙 加班施工 / ⏰ 施工超时施工中已超预约结束时间；超过 30 分钟宽限后提示。其中过了当天 18:00 显示红色「加班施工」，否则琥珀「施工超时」红 / 橙徽标
⏰ 已延期通过「项目延期」流程改期（带原因）后红色徽标 + 高亮，记录原时间
⏸️ 暂停过久暂停施工超过 24 小时未恢复（疑似忘记恢复）红色徽标 + 高亮

📌 高亮强度区分

提醒的红色分两级：🚨 忘记施工 / 🌙 跨夜未完工 用强红高亮（红边框 + 脉冲动画），属于"明显异常、必须处理"；而 🌙 加班施工 / ⏰ 施工超时 等用普通红 / 橙高亮（浅色边框、无脉冲）——加班赶工属正常业务，不升级为强提醒。请勿将两类"红色"理解为同样紧急。

💡 阈值说明

连续施工超时阈值：默认 12 小时，可调范围 1–168 小时，云端模式写入数据库全员生效，本地模式仅本机生效。

加班 / 施工超时宽限：超过预约结束时间满 30 分钟才提示，避免刚到点收尾误报；提示的"已加班 / 已超预约时长"从预约结束时间起算（不含宽限）。

暂停过久阈值：固定 24 小时。

验收后自动审核：默认关闭（0）。设置后，项目「确认验收」满该时长（小时）会自动审核通过（置为「已审核」）。例如填 72 表示验收满 3 天自动审核。云端模式写入数据库全员生效；本地模式仅本机生效。

📌 自动审核的执行条件

自动审核在浏览器开着页面时每分钟检查一次，且只对当前登录账号有审核权限的项目生效（审核为权威操作，需审核权限）。因此需有审核权限的账号（如总经理）保持应用页面打开，才会自动执行；无人开着页面时不会审核。审核后项目即锁定（不可再改工时，仅经理级可强制改）。

二、忘点完工的考勤处理（重要）

⚠️ 自动考勤可能失真

忘点完工的项目（跨夜 / 连续超时），系统按在场时段自动生成的考勤工时可能包含空闲、过夜时间，并非真实工时。打开「完成施工」表单时：

  • 表单顶部会提示该项目疑似忘点完工，请先核对施工状态（若实际早已完工，应改状态而非直接完工）；
  • 考勤工时为只读预览，不要求也不允许手动逐人核填——包活制下工时不影响工资，无需为考勤纠结；
  • 若自动考勤明显失真（如跨夜时长被整段计入），可在完工后到项目详情页删除对应考勤记录，系统重新汇总即可。

包活制下，考勤工时完全不进入工资结算；客户费用与工人分成只取决于"工费的一半"与分配方式，与施工时长脱钩，因此考勤只需大致如实、不必逐人精确。

施工用时偏短不再提示：包活制下施工时长不作为考核点（长短不影响客户费用与工人分成），系统已移除"施工用时偏短"的表单告警与拦截。

🔔 消息中心与站内通知

系统提供统一的消息中心，集中展示系统自动派发的提醒与成员手动发送的通知。支持多端实时接收、红点角标与桌面弹窗提醒，让重要事项不再被淹没在列表里。

一、入口与未读角标

  • 桌面端：右上角头像下拉菜单中的「🔔 消息」入口，旁边显示未读红点角标。
  • 移动端：底部导航的「🔔 消息」标签，有未读时标签上显示红点。
  • 头像角标：当前账号有未读消息时，头像右上角出现红点提示，无需点开即可知道"有新消息"。

二、消息类型

类型说明
系统自动通知系统根据业务事件自动派发。例如：项目完工后派发给本门店店长"待验收"提醒；项目超期 / 忘记开工时自动通知本门店店长；开始施工 / 暂停 / 完工等关键节点也按规则通知相关门店店长。其中超期与忘记开工两类提醒遵循「同一项目同一状态每轮只提示一次」——同一轮内即使多设备/多人同时在线也只发一条；项目状态解除（完工/开工/恢复）后即清零，若之后再次超期 / 忘记开工，会再次提醒。
成员手动通知拥有发送权限的成员，可在消息中心点击「＋ 发通知」，主动给团队成员发送通知（如临时调度、注意事项等）。

三、桌面弹窗提醒（Toast）

收到新消息时，电脑端右下角会弹出消息卡片，显示标题与摘要，可一键「查看」或「标记已读」，数秒后自动消失。同时消息中心红点同步更新——即便不主动去消息中心，也不会错过重要通知。

四、发送通知

1. 打开发送入口

在消息中心点击「＋ 发通知」按钮（仅在云端模式、且当前账号有发送权限时显示）。

2. 选择接收范围

所有人：发送给全体云端成员；本门店：仅发送给当前账号所属门店成员；指定人员：从成员列表中勾选具体接收人（可多选）。

3. 填写内容并发送

填写标题与正文，点击「发送」。接收方将在消息中心看到该通知，并收到红点 / 弹窗提醒。

💡 发送权限

云端模式下所有已登录成员默认拥有发送通知的权限（由系统统一开放，无需单独授予）；接收范围对所有成员平等，店长也可向跨门店成员发送。本地模式无云端账号，不提供消息中心。

五、管理消息

  • 标记已读 / 全部已读：点开消息自动标记已读；消息中心提供「全部已读」按钮批量清除未读状态。
  • 清除单条：每条消息卡片旁提供清除按钮，可删除单条通知（仅影响本端显示）。

六、实时接收

云端模式下，新消息通过实时通道即时推送到其他已登录成员；若实时通道临时不可用，系统每 15 秒自动轮询兜底，确保消息延迟不超过 15 秒到达，无需手动刷新。

账号信息维护

  • 姓名：支持行内直接修改
  • 角色：待分配 / 施工人员 / 店长 / 总经理（决定默认权限集合）
  • 所属门店：绑定门店后仅能查看本门店数据（店长及以上可跨门店）
  • 删除：删除操作不可撤销，需二次确认

分人个性权限（云端）

💡 在角色默认之上单独设置

管理员可对单个非总经理的云端用户单独授予或收回某项能力。未改动的项自动继承该角色的默认权限；改动过的项显示「已单独设置」，实时对全员生效。

权限项覆盖业务全流程，常见包括：

  • 预约类：新建预约、编辑/删除自己的或所有的预约、修改自己项目预约时间/修改所有项目预约时间（勾选「编辑所有项目」或「编辑自己项目」也自动包含改预约时间）、查看所有门店项目
    ⚠️ 注意：这些预约类权限只在项目开工前有效。项目一旦开始施工或进入终态，预约时间即被锁定，任何权限都无法修改，改期请走「延期」流程。
    ✔ 预约工时（预计总工时）已由「施工时段 × 已分配人数」自动派生，不再需要单独授权——改了预约时间，工时会自动跟着重算。
  • 施工类：开始/暂停/恢复/完成施工、分配/移除安装人员、删除考勤工时记录（纠错用——包活制下工时由系统按在场时段自动生成、不再手动填写，故只有"删除"没有"填写"）
  • 人员类：添加/编辑/删除施工人员、查看施工人员
  • 审批类：申请/批准/拒绝请假、验收项目、审核/反审核项目
  • 通知类：发送通知（云端模式默认所有已登录成员均可发送；可指定接收范围：全员 / 本门店 / 指定人员）
  • 统计与管理类：查看全局或门店统计、管理门店、管理账户、管理节假日、管理外协、维修单等
  • 数据工具类（各自独立开关）：导出项目数据 / 工时记录 / 休假记录 / 施工人员 / 门店数据 / 全部数据、数据导入、查看操作日志
  • 包活结算类（各自独立开关）：修改包活金额（包工 / 包工包料、工程金额、材料费）、修改工人分成（平均分配 / 自定义比例 / 按金额分配）。默认总经理与门店经理可改，施工人员只读。
    ※ 改的是工钱，所以这两项带门店兜底：拥有「编辑所有项目」权限（或总经理 / 未绑定门店的账号）才能改全部门店；否则只能改本门店项目，与他店的「改预约时间 / 返工 / 审核 / 编辑项目」口径一致
  • ✏️ 改金额快捷入口：项目详情里的绿色「💰 包活 / 工程金额 / 工费 / 工人分成池」摘要块，整块可点，弹出小窗直接改包活方式与金额，边输入边实时显示新的工费与分成池——不必回预约表单里翻找。该入口同样受「修改包活金额」权限控制；没有该权限的人看到的是纯展示（无悬停高亮、无「改金额」标签），已审核项目一律锁定
  • 📋 金额改动留痕：快捷弹窗里改过的包活方式 / 工程金额 / 材料费，会记成一条「💰 修改包活金额：旧值 → 新值（工费 ¥x，分成池 ¥y）」，有两个地方可查——① 项目详情页绿色包活块下方直接显示最近一次修改（日期 + 操作人 + 新旧值）；② 页面往下滚到「📝 施工记录」，最底部的「📋 操作日志」折叠面板里有完整历史。全局操作日志也同步留一条。金额没动则不产生记录
  • ⚠️ 改金额会连带改工人分成：快捷弹窗里实时显示「每人分成 旧 → 新」（红色=变少、绿色=变多），保存前一目了然。三条规则——① 分配比例不受影响，池子变小内部工人按原比例同比缩水；② 外协固定工钱会随新池联动：若缩小后的池装不下外协固定额，保存时自动按同比例缩小外协（否则外协金额不变、工人被砍光），并在弹窗与 toast 里提示；③ 已完工 / 已验收 / 已审核的项目改金额会直接改变已计入统计的提成，保存前额外弹一次确认，逐人列出旧→新金额。取消确认会保留你已填的内容不丢
  • 个人日程类（各自独立开关）：查看个人日程、查看全员日程、添加日程、编辑自己的日程 / 编辑所有日程、删除自己的日程 / 删除所有日程

📤 数据导入与导出

「我的 → 数据工具」中的每一项功能，均由对应的独立权限开关控制，可精确授权给需要的成员（无需整体开放）：

数据导出（各自独立权限）

  • 导出项目数据 / 工时记录 / 休假记录 / 施工人员 / 门店数据：分别由对应的导出权限控制，可只放开其中一类
  • 导出项目数据：CSV 含包活金额字段（工程金额、材料费、工费金额、工人分成合计、分成池、包活方式、分成方式）便于对账，工时列标注「(考勤)」仅作参考
  • 导出工时记录：考勤明细全量导出，不含「是否计薪」列——包活制下工时不再参与工资计算
  • 导出全部数据：打包所有业务数据，便于备份或迁移（单独的「导出全部数据」权限）
  • 车辆记录导出 Excel：在车辆页将筛选后的用车记录导出为 Excel
  • 导出统计数据：在「提成统计」页按筛选范围导出提成统计报表——统计概览、人员提成、每日提成明细、项目提成明细、项目人员提成明细（含施工内容 / 注意事项、效果图、分配比例、个人提成），以及每位工人一张的提成核算表（含包活提成明细、每日提成日历与工资核算）；请假 / 轮休记录自动附工作表
  • 店面预约统计导出 Excel：在「店面预约统计」页，按所选统计月份导出为多工作表工作簿——门店汇总（各门店预约数 / 工程金额 / 工费合计）、项目明细（该月份全部项目合并，含工程金额、工费与开工偏差），以及按门店拆分的项目明细（每个有项目的门店各一张工作表，仅含该月份项目）；表头冻结、偏差列按红绿着色
  • 操作日志：由「查看操作日志」权限控制，查看系统关键操作记录，便于审计追溯

数据导入

具备「数据导入」权限的成员，可导入 CSV 文件批量录入数据，支持类型：

  • 项目数据、工时记录、施工人员、门店数据、休假记录、外协人员

导入方式

点击「数据导入」→ 选择文件类型按钮，或直接拖拽 CSV 文件到窗口；系统也可根据文件名（含「工时」「人员」「门店」「请假」「外协」等）自动识别类型

💡 导入结果

导入后界面会显示成功条数与失败条数；部分失败不影响其余记录，可修正后重新导入。

📱 个人中心与系统设置

个人中心（我的）

底部「我的」页汇总个人与团队入口：

  • 功能中心：按权限展示施工人员、外协、请假、个人日程、门店、统计、账号管理等
  • 数据工具（管理员/有权限者）：各类导出、操作日志、数据导入、导出全部、帮助与反馈
  • 管理员设置（仅云端总经理）：提醒设置、管理密码设置
  • 登出：云端模式提供退出登录

本地模式与云端模式

  • 本地模式：数据仅存本机，适合单机使用；可添加本地账号
  • 云端模式：数据存于云端，多设备实时同步，支持团队协作与权限分级

💡 实时同步

云端模式下，预约、施工、工时、车辆、权限等变更会通过实时通道推送到其他已登录成员，无需手动刷新即可看到最新数据。

移动端同步状态胶囊

移动端顶部显示一枚同步状态胶囊，实时反映与云端的同步情况。图标均为内嵌矢量图形（非 emoji），在任何手机 / 系统上都不会出现"方块乱码"。

状态图标表现说明
同步中左侧靛蓝小圆点 + "同步中…"同一浅灰胶囊的左端状态点着靛蓝，表示与云端同步进行中；点击可手动触发同步
同步完成左侧绿色小圆点 + "同步完成"状态点着绿，表示最近一次同步成功；点击可立即再同步一次
已同步左侧灰色小圆点 + "同步于 HH:MM"状态点着灰，显示上次成功同步时间与相对时间（如"3 分钟前"）
同步失败左侧红色小圆点 + "同步失败"状态点着红，本次同步出错；点击可重试

管理密码（云端总经理）

云端总经理可设置管理密码，作为敏感操作（如权限调整）的二次校验；未设置时入口会提示「（未设置）」。

登录密码安全

云端模式下，所有成员可在「我的 → 修改登录密码」中修改自己的登录密码（需先输入当前密码验证，适合公共设备）。

  • 密码强度检测：注册和修改密码时实时检测，要求至少 8 位、且同时包含大写字母、小写字母和数字（符号可选）；输入框下方有强度条实时提示。
  • 强制修改密码：管理员在「我的 → 账号管理」中可标记某成员「下次登录须修改密码」。被标记者下次登录会弹出不可关闭的强制改密弹窗，必须设置符合当前强度标准（8 位+含大小写字母和数字）的新密码、修改成功后方可继续使用（也可选择退出登录）。标记时管理员会收到「新密码需 8 位+含大小写字母和数字」的提示。
  • 管理员重置密码：在「我的 → 账号管理」中，总经理可点击某成员的「重置密码」，将其密码重置为系统生成的初始密码（≥8 位、含大小写字母和数字，管理员可手动修改）。重置后该成员下次登录会被强制改密；弹窗会展示初始密码，请复制并私下发给该成员，由其首次登录时改为自己的密码。该操作需部署 reset-password Edge Function（用服务端 service_role 改写 Auth 密码）。
  • ⚠️ 存量弱密码账号怎么处理：系统读不到 Supabase 已存的密码，无法自动扫描「谁现在密码弱」。建议做法——若怀疑某成员密码过弱，直接在「账号管理」标记其强制改密，让其下次登录按新标准重设即可；或提醒本人到「我的 → 修改登录密码」自行改密。

安装为桌面 / 主屏应用

💡 像 App 一样使用

本系统支持 PWA（渐进式 Web 应用），可像原生 App 一样安装到桌面或手机主屏，全屏运行、可离线使用。

  • Chrome / Edge / 安卓浏览器：在登录界面点击「📲 安装到桌面 / 主屏」按钮（仅在浏览器支持安装时显示），或直接接受浏览器弹出的安装提示，即可一键安装；安装后从桌面 / 主屏图标打开即进入应用。
  • iOS Safari：暂不支持代码呼出安装框，请在登录界面按提示，点击底部「分享 ⤴」→「添加到主屏幕」。
  • 已安装后，安装入口会自动隐藏；如需卸载，在桌面 / 主屏长按图标删除即可。
  • 长时间后台会自动刷新：应用退到后台（或手机锁屏）超过设定时长（默认 15 分钟）后再次打开时，会自动重新加载一次（相当于杀掉后台冷启动）。因为核心文件均已本地缓存，这个「冷启动」很快；后台较久时它能绕开系统把页面「冻结」后原地恢复那条较慢的路径，反而比直接唤醒更顺畅。若当时有弹窗或正在填写的表单打开，会自动跳过本次刷新，不打断你的输入。数据始终在云端 / 本地缓存，刷新不会丢失。阈值可在「个人中心 → 应用设置 → 后台自动刷新」里自定义（5 / 10 / 15 / 30 / 60 分钟，或关闭）。
