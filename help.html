🔄 核心工作流程总览

新建预约 → 分配人员 → 开始施工 → 施工中/暂停/恢复 → 完成施工（登记工时）→ 验收 → 审核

系统围绕项目生命周期设计，从预约创建到最终审核，每个环节都有明确的操作和数据记录。

💡 流程特点

系统支持灵活的人员变动管理（加人/减人），自动计算已移除人员的工时；支持多次暂停/恢复，暂停期间不计入工时；完工时自动汇总所有参与人员的工时记录。

📊 项目状态流转

预约中 → 施工中 ↔ 已暂停 → 已完工 → 已验收 → 已审核 ↓ ↓ 已取消 已延期

状态说明

状态颜色说明进度条颜色
预约中🔵 蓝色项目已创建，等待施工蓝色
施工中🔵 蓝色项目正在进行蓝色
已暂停🟠 橙色项目暂时停止，可恢复橙色
已延期🔴 红色项目超出预计时间未完工红色
已完工🟢 绿色安装完成，工时已登记绿色（100%）
已验收🟣 紫色验收通过绿色（100%）
已审核🔵 青色财务审核完成绿色（100%）
已取消🔴 红色项目已取消灰色

状态流转规则

  • 预约中 → 施工中：点击"开始施工"，必须先分配安装人员
  • 施工中 ↔ 已暂停：可多次暂停和恢复，暂停期间不计入工时
  • 施工中/已暂停 → 已延期：点击「项目延期」按钮（需填原因）改期，系统也会针对超时未完工提示延期
  • 任意状态 → 已取消：需填写取消原因，取消后只读
  • 施工中/已暂停/已延期 → 已完工：必须登记工时
  • 已完工 → 已验收 → 已审核：逐级审批，不可逆

📝 项目预约流程

第一步：新建项目预约

1.1 填写项目基本信息

项目名称、客户名称、联系电话、门店、安装地址

1.2 设置预约时间

选择日期和开始时间。结束时间可点「计算」按钮，按 预计工时 ÷ 施工人数 推算现场占用时长（开始时间 + 该时长），也可手动选择。

快捷时间：提供「2小时 / 上午 / 下午 / 全天」一键填入开始与结束时间——上午 08:00–12:00、下午 13:00–18:00、全天 08:00–18:00、"2小时"以当前开始时间为准往后推 2 小时。

1.3 设置预计总工时

预计总工时非强制必填：留空或保存时未手动改动，系统会自动按"施工时长 × 施工人数"计算并给出提示。

1.4 分配施工人员

选择内部施工人员或填写外协人员（外协人员不参与时间冲突检测）

1.5 保存项目

点击"保存"完成创建，项目进入"预约中"状态

💡 快捷操作

当选择今天日期时，开始时间自动根据当前系统时间向上取整，结束时间默认往后推2小时

人员冲突检测

分配人员时系统会自动检测时间冲突，如果该人员在此时间段已被分配到其他项目，会弹出提示。您可以选择是否继续分配。

📅 修改预约时间留痕（已改期）

预约中的项目，通过编辑项目、时间轴拖拽、或快捷改期修改过预约时间后，系统会永久保留最初排期并显示「📅 已改期」标记：

  • 卡片：紫色「📅 已改期」徽标；
  • 详情页：施工记录区显示「已改期 · 原预约 + 原时间」紫色卡片，一眼看到最早约的几号几时；
  • 时间轴：任务条上显示「📅 已改期」。

💡 与「延期」的区别

普通改期只是静默改时间并留痕，状态仍是「预约中」；「延期」是带原因的另一套流程，状态变为「已延期」并保留原时间 + 原因。已延期状态不再叠加「已改期」徽标，避免重复。

📅 跨天施工预约

当一个项目一天干不完、需要分多天施工时（例如：第一天 7:00–20:00、第二天 8:00–16:00，中间留足休息 / 睡觉时间），使用「跨天施工」功能。系统按「每日独立施工时段」建模，而不是把时间连续拉长到跨午夜——这样既符合真实的作息，也不会在工时与预警上产生误判。

什么时候用跨天

  • 单日施工窗口（如 8:00–18:00）装不完，需顺延到第二天上午 / 下午继续；
  • 多日连续作业，但每天都有独立的开工、收工时间，夜里不施工；
  • 工期分散在多个日期（如 D1、D3、D5 各干一段），也可逐天添加。

📌 与「夜间 / 跨午夜」的区别

「跨天」是多天各一段（中间有休息），不是"从今晚干到明天凌晨"。系统对开工后跨午夜仍在施工中的项目会判定为「🌙 跨夜未完工」（疑似忘点完工）；而正常的跨天施工是每天各自收工、第二天再开工，不会触发该预警。

如何设置跨天预约

1. 填写第一天

在「新建 / 编辑项目」弹窗，按正常方式填好第 1 天的日期、开始时间、结束时间（即主预约时间）。系统会自动算出这一天的现场占用时长。

2. 点击「➕ 添加一天（跨天施工）」

在预约时间区域下方，点击该按钮新增第 2 天的分段行。新行默认填为下一天 08:00–18:00，可手动改为实际日期与时段（如第二天 8:00–16:00）。

3. 继续添加更多天

按需重复点「➕ 添加一天」，每行相互独立、日期自动顺延；某天不干了可点该行右侧的「✕」删除。每行都显示「第 N 天」标签 + 日期 + 开始 / 结束时间。

4. 查看总时长与建议人数

表单实时按所有分段时长求和显示「总施工时长」（如「2天 共31小时」）；并据「总工时 ÷ 总时长」给出建议施工人数。预计总工时未手填时，自动 = 总时长 × 人数。

跨天时「计算」按钮会自动隐藏：因为单日连续推算结束时间会破坏多段设置，跨天项目不再使用「总工时 → 结束时间」的计算方式，而是由你直接控制每一天的分段。

5. 保存

点击「保存」后，项目按多段日程入库：开始时间取首段起、结束时间取末段止，分段明细存入「施工时段」。

跨天在各视图的显示

  • 时间轴 / 日历：按当前选中的日期逐日裁剪，只显示该项目当天那段施工窗口（不会把多天拼成 24h+ 长条）；任务条带「📅 跨天 N 天」徽标；禁止直接拖拽改期（拖动会破坏分段数据），要调整请回「编辑项目 / 修改预约」弹窗的跨天分段里改。
  • 项目卡片：标题区带「📅 跨天 N 天」徽标；"预约时长"显示真实施工工时（各段时长之和，不含夜间睡觉）；开工后卡片时间线按 workSessions 逐段列出每天实际施工时段并给出合计；卡片预约时间显示为「首段起 ~ 末段止（带日期）」。
  • 项目进度跟踪（施工管理页）：跨天项目每天都会出现在对应日期；显示「📅 第 N 天 / 共 N 天」徽标与「第 N 天 · 当天时间段」（如「第 2 天 · 08:00~18:00」），一眼看清当天该干什么。
  • 工时统计：跨天项目的实际工时优先取登记工时（完工时逐人填的）；施工管理页还会列出跨天项目工时明细——各分段范围 + 实际 / 计划工时，避免只看汇总数字被误导。

注意事项

  • 每一天的结束时间必须晚于开始时间，否则保存时会提示「每段结束时间需晚于开始时间」。
  • 跨天施工时，预计总工时 = 各段时长之和 × 施工人数；只要没手动改动过工时框，保存时会自动按此公式回填。如需 Override，直接手工填写即可。
  • 跨天分段与普通过夜一样，一旦开工即锁定：已开工 / 终态项目的预约时间、分段数据不可再改（改期请走「延期」流程）。
  • 分段数据向后兼容旧项目：没设分段的旧单天项目，系统自动按原预约起止时间合成单段，不受影响。
  • 「✏️ 修改预约」同样支持跨天：在卡片弹窗点「✏️ 修改预约」或「✏️ 编辑」打开的表单，也能查看 / 增删跨天分段；保存时保留全部分段，不会把多日项目误存成单日、丢失数据。
  • 🟠 跨天提前完工会被拦截提示：如果还没干到预约末天就点「完工」，表单顶部弹橙色警告——说明应每天结束点暂停、次日点恢复、最后一天再完工，并要求逐人手动填真实工时（自动分配滑块被隐藏）；点「确认完工」时还会二次确认，避免误点把工时算错。确实要提前收工，手动填好每人真实工时再确认即可。

⚙️ 施工管理流程

第一步：进入施工管理

从项目预约卡片点击「施工管理」按钮，进入项目详细管理页面。

第二步：分配安装人员

2.1 添加人员

在"安装人员分配"区域，点击"+"按钮选择施工人员，系统自动记录分配时间

2.2 移除人员

点击人员旁边的"×"按钮移除，系统自动计算该人员从开工到移除的工时并记录

💡 自动工时计算

移除人员时，系统自动计算：工时 = 总施工时间 / 施工人数（平均分配），并自动创建工人工时记录

第三步：开始施工

3.1 检查人员分配

系统自动检查是否已分配安装人员，未分配时提示先分配人员

3.2 记录开工时间

点击"开始施工"按钮，系统记录当前时间为开工时间，项目状态变为"施工中"

第四步：施工过程管理

4.1 暂停施工

点击"暂停施工"按钮，填写暂停原因（可选，支持快速选择或手动输入），系统记录暂停时间，暂停期间不计入工时

4.2 恢复施工

点击"恢复施工"按钮，系统记录恢复时间，从当前时间重新开始计时

4.3 项目延期

点击"项目延期"按钮，设置新预约时间（默认8:00）和延期原因，系统记录延期历史

💡 进度条显示规则

施工中：蓝色进度条，根据墙钟时间（累计工时+当前工作时长）×施工人数计算进度

已暂停：橙色进度条，暂停期间进度不再增加

已延期：红色进度条，提示项目超期

已完工：绿色进度条，固定显示100%

第五步：完成施工

5.1 打开完工表单

点击"完成施工"按钮，系统自动汇总所有参与人员（包括已移除人员）

5.2 登记工时

已移除人员的工时自动填入（系统自动计算的结果），当前人员需手动填写工时、等级和备注

5.3 确认完工

确认总工时，系统自动记录完工时间，项目状态变为"已完工"

💡 工时自动汇总

完工表单会显示所有曾经参与过该项目的工人，包括：

  • 当前分配的工人（显示为正常颜色）
  • 已移除的工人（显示为灰色，标注"已移除"）
  • 已移除工人的工时会自动填入（基于系统自动计算）

📌 工时登记的操作时机

「添加工时」表单与工时的修改 / 删除，只在「施工中」与「已暂停」状态可用。预约中（尚未开工）不能登记工时；已完工 / 已验收后的工时已锁定，不再显示登记入口，避免污染已结算数据。

已完工工时登记有误如何更正？项目进入终态（已完工 / 已验收 / 已审核）后，若发现某条施工工时填错，拥有「修改完工工时」权限（修改自己项目的完工工时 / 修改所有项目的完工工时）的成员可在施工详情页点击「✏️ 修改工时」，逐人、逐段更正作业类型、等级、工时与备注。修改会记入操作日志便于审计，且不影响预约时间 / 预约工时的终态锁定。

取消项目

⚠️ 不可逆操作

点击"取消项目"按钮，填写取消原因，项目将标记为"已取消"，保留在系统中便于追溯，但无法再进行任何操作

👷 人员管理流程

人员分配流程

添加人员 → 记录分配时间 → 参与施工 → 移除人员（自动计算工时）→ 记录移除时间

人员变动记录

每次人员分配和移除操作都会记录到施工记录中，包括：

  • 操作时间
  • 操作类型（分配/移除）
  • 人员姓名和联系方式
  • 移除时自动计算的工时

工人工时统计

施工记录中的"工人工时统计"区块显示：

  • 每个工人的累计工时
  • 当前施工人员（绿色）和已移除人员（灰色）
  • 内部人员和外协人员（紫色标识）
  • 每个工人的工作时间段
  • 自动记录工时的标记

⏱️ 工时管理流程

工时计算规则

实际工时 = 所有工人工时记录之和（包括自动记录和手动登记）

工时记录方式

  • 自动记录：移除工人时系统自动计算并记录工时
  • 手动登记：完工时在表单中手动填写工时
  • 外协工时：单独登记外协人员工时，以紫色标识

工时等级

等级说明用途
初级简单安装任务，技术要求低基础工时结算
中级常规安装任务，标准技术要求（默认）标准工时结算
高级复杂安装任务，需要专业技能较高工时结算
特级高难度任务，需要特殊资质或高空作业最高工时结算

工时差异计算

工时差异 = 实际工时 - 预计工时

  • 正数（超）：实际工时超过预计工时
  • 负数（省）：实际工时少于预计工时

预计工时自动计算

💡 智能计算（新建 / 编辑均适用）

预计总工时采用"按需自动计算"策略，新建与编辑保存时都生效：

  • 未填写预计总工时：保存时系统自动按 施工时长 × 施工人数 计算并保存，同时给出提示。
  • 未手动改动过工时框：保存时同样以 施工时长 × 施工人数 重算——即修改了施工起止时间段后，只要没手动改工时，总工时会自动跟随重算。
  • 手动填写 / 修改过工时框：以手动输入值为准，不再被自动覆盖。

计算公式：预计总工时 = 施工时长 × 施工人数。例如：施工时间 2 小时、2 人施工，预计总工时 = 4 小时。

✅ 验收审核流程

验收流程

1. 填写验收信息

验收人、验收时间、验收类型、验收方式、验收结果、验收结论

2. 验收项检查

安装位置准确、安装牢固、外观整洁等检查项

3. 提交验收

点击"确认验收"，项目状态变为"已验收"

审核流程

1. 审核工时

查看项目工时记录和工时差异

2. 审核验收结果

确认验收结论和检查项

3. 提交审核

点击"审核项目"，项目状态变为"已审核"，记录审核时间

取消审核

已审核项目如核对有误，可在审核/验收页「取消审核」，退回为「已完工」状态重新走验收流程。

📌 验收信息的显示时机

「验收信息」区块只在项目进入终态后显示：已完工（显示「填写验收信息」按钮）、已验收 / 已审核（显示验收记录与「修改验收」）。施工中 / 预约中 / 已暂停 / 已延期时不显示，避免提前误点。已取消项目仅在有验收记录时显示。

⚠️ 开工锁定与终态锁定

① 开工即锁定：项目一旦开始施工（进入「施工中」「已暂停」，或曾经开工过），其预约时间与预约工时（预计工时）立即锁定，即使拥有「修改所有项目预约时间 / 预约工时」权限也无法再改。因为预约时间与预约工时在开工那一刻就成为考核基准（用于对比实际工时、统计准点率），事后修改会让统计失真。

需要改期怎么办？使用施工管理页的「📅 延期」功能——它会要求填写延期原因，并完整保留原预约时间与延期记录，既能改期又不破坏可追溯性。实际耗时则通过「登记工时」记录。

② 终态锁定：项目进入已完工 / 已验收 / 已审核后同样锁定，编辑页相关字段变为只读。取消审核退回「已完工」后仍属终态保护，预约时间与工时保持锁定。

不受影响的情况：「预约中」的项目，以及由「预约中」延期而来（尚未开过工）的项目，仍可正常修改预约时间与工时。项目的名称、客户、地址、备注等基本信息在开工后也仍可编辑（需「编辑项目」权限），只有预约时间与预约工时被锁。

🔄 返工管理

原项目已完工 / 验收 / 审核后，因质量等问题需要再次施工时，使用「返工」功能。返工会生成可独立排期、独立核算的施工任务，并自动关联回原项目，便于追溯。

发起返工

在终态项目（已完工 / 已验收 / 已审核）的施工管理页，点击「🔄 返工」按钮，弹出返工表单。

填写返工表单

预约时间

选择返工日期、开始与结束时间段（提供快捷时间段按钮），即再次施工的排期。返工不一定立即施工，可预约到未来的某天。

返工内容（必填）

填写需要返工的具体内容，作为独立字段记录；施工人员打开返工单可清楚看到要做什么。

注意事项

可填写返工时的特别注意事项。

人数与工时

默认预填原项目的施工人数与工时，可按实际情况修改。

两种返工模式（单选）

模式说明对原项目的影响
🆕 新建返工单生成一条独立的新预约（状态=预约中），与原项目并存不变；原项目详情会列出「🔄 返工单」及返工内容摘要，并聚合显示返工工时
♻️ 转回老单重做把原项目本身改回「预约中」并重填时间 / 返工内容 / 工时历史工时保留、项目名不变，重新走施工→完工流程

关联与追溯

  • 返工单详情页显示「返工源自：<原项目名称>」，可点击跳转回原项目。
  • 原项目详情页显示「🔄 返工 N 次」徽标，并在「返工单」区块列出每条返工单（名称 / 状态 / 工时 / 返工内容摘要）。

返工工时计薪

⚠️ 仅财务 / 有「查看全局统计」权限者可见

返工单详情页底部提供「返工工时计入工资」开关：

  • 勾选：返工工时计入工人工资（与正常项目工时一致参与结算）。
  • 取消勾选（默认）：返工工时仅作成本核算——统计中单列「返工工时」成本卡，但不进入工人工资。

施工人员 / 非财务角色打开返工单看不到此开关。开关可随时修改，立即生效。

🔧 维修单

原项目已完工 / 验收 / 审核后，因客户报修需要上门维修时，使用「维修单」。维修单挂在原项目上（作为待办），不会改写原项目的预约时间，因此不会污染已完工原单在时间轴、人员安排与日历里的展示。

同一项目可多次维修

维修单以列表形式挂在原项目上，支持同一项目多次发起（如修了又坏）。每条维修单有独立编号（#1、#2…）、独立预约维修时间与状态。详情页「维修单」区块会列出全部维修单，每条可单独完成 / 改期 / 删除；点击「🔄 再发起维修单」可新增一条待维修单。

完成维修必记工时

完成维修时弹出行内表单，需勾选参与维修人员并填写真实工时（维修必记工时，用于成本核算）。同时需选择维修性质：

  • 🆓 免费保修（默认）：仅作成本核算，不计入工人工资。
  • ✅ 付费维修：工时计入工人工资，参与工资统计结算（仅财务 / 可看全局统计角色可见此选项）。

此逻辑与返工一致：只有「付费 / 计薪」性质的工时才会进入工资统计，免费保修仅在成本侧体现。

进入待处理提醒

状态为「待维修」的维修单会出现在首页「待处理提醒」汇总区（超预约未修显红色），也出现在时间轴、人员安排与日历的对应日期，便于提前安排。

🚗 车辆管理

系统提供车辆使用与里程管理，记录每辆车的使用人、里程与油耗，便于车辆调度与成本核算。

车辆看板

首页「车辆」页以卡片展示每辆车的状态概览：

  • 车型 / 车牌：车辆基本信息
  • 状态：🔒 使用中 或 空闲；使用中卡片会显示当前司机「👤 司机姓名」
  • 当前里程：使用中显示出发时里程，空闲显示最近一次还车里程
  • 本月里程：当月累计里程，与「月度目标里程」对照，圆环显示完成比例
  • 剩余油量：空闲时显示上次还车记录的油量（低于 20% 红色、40% 橙色提醒），未记录则提示

用车登记

1. 选择车辆

在车辆卡片上点击展开「用车」面板（空闲车显示「用车 ▸」）

2. 核对起始公里数

系统默认带出上次里程，请对照仪表核对，如不符可当场修改校准

3. 填写用车信息

开车目的：送货 / 接货 / 安装 / 业务（分段选择）；关联项目（可选，自动过滤已完工、已验收、已审核的项目）；司机（必填，可输入新增）；备注 / 目的地

4. 确认用车

点击「确认用车」后车辆进入「🔒 使用中」状态，卡片显示司机姓名，其他人可见谁在用车

还车结算

1. 展开还车面板

在使用中卡片上点击「还车 ▾」

2. 填写回来公里数

起始公里数已锁定不可改，填写当前仪表读数后系统自动结算本次里程

3. 登记剩余油量与备注

填写剩余油量（0–100%）及还车备注（如车辆状况、是否加油）

4. 确认还车

点击「确认还车」，车辆转为空闲并记录本次行程（里程、油耗、司机、时间）

💡 用车提示

用车时选择：目的、关联项目或填写备注；若与仪表不符可当场修改校准。还车时请填写仪表里程和剩余油量，系统自动结算本次里程。车在使用中显示「🔒 使用中 · 司机」，用车完毕请及时还车。

历史记录与导出

  • 支持卡片 / 列表两种视图，可按车辆、司机、日期筛选；列表视图以表格展示，列含：车辆、用途、司机、出发、返回、里程、操作（车辆信息单行显示，用途如安装/送货为独立列）
  • 可将筛选后的用车记录导出为 Excel，便于报销与核算

🔔 预警与待处理提醒

📌 仅总经理可设置

提醒标准为全局统一配置，由总经理在「我的 → 管理员设置 → 提醒设置」中调整，对全体成员的提醒标准一致。其他角色在界面上看不到该入口。

一、项目类预警

项目预约列表与施工详情卡片会针对以下异常自动标红 / 高亮并置顶，提醒尽快处理：

预警触发条件表现
🚨 超时未开工预约时间已过仍未开工（含历史任何日期）红色徽标 + 高亮
🌙 跨夜未完工开工后跨午夜仍在施工中（不可能整夜施工，必为忘点完工）红色徽标 + 强红高亮
⚠️ 连续施工超时连续施工超过总经理设定的阈值（默认 12 小时；中途暂停不计入）橙色徽标
🌙 加班施工 / ⏰ 施工超时施工中已超预约结束时间；超过 30 分钟宽限后提示。其中过了当天 18:00 显示红色「加班施工」，否则琥珀「施工超时」红 / 橙徽标
⏰ 已延期通过「项目延期」流程改期（带原因）后红色徽标 + 高亮，记录原时间
⏸️ 暂停过久暂停施工超过 24 小时未恢复（疑似忘记恢复）红色徽标 + 高亮

💡 阈值说明

连续施工超时阈值：默认 12 小时，可调范围 1–168 小时，云端模式写入数据库全员生效，本地模式仅本机生效。

加班 / 施工超时宽限：超过预约结束时间满 30 分钟才提示，避免刚到点收尾误报；提示的"已加班 / 已超预约时长"从预约结束时间起算（不含宽限）。

暂停过久阈值：固定 24 小时。

验收后自动审核：默认关闭（0）。设置后，项目「确认验收」满该时长（小时）会自动审核通过（置为「已审核」）。例如填 72 表示验收满 3 天自动审核。云端模式写入数据库全员生效；本地模式仅本机生效。

📌 自动审核的执行条件

自动审核在浏览器开着页面时每分钟检查一次，且只对当前登录账号有审核权限的项目生效（审核为权威操作，需审核权限）。因此需有审核权限的账号（如总经理）保持应用页面打开，才会自动执行；无人开着页面时不会审核。审核后项目即锁定（不可再改工时，仅经理级可强制改）。

二、忘点完工的工时处理（重要）

⚠️ 自动工时不可直接采用

忘点完工的项目（跨夜 / 连续超时），系统自动算出的工时包含空闲与过夜时间，不是真实工时。打开「完成施工」表单时：

  • 表单顶部显示红色警告，说明需逐人手动填写真实工时；
  • 每位工人的工时预填被清空，备注「⚠️请填真实工时」；
  • 「应用到所有施工人员」等批量分配操作被拦截，强制手动核填后才能提交。

三、「待处理提醒」汇总区

在「人员安排」（管理页）与「我的安排」（工人页）顶部，统一汇总所有"该处理却没处理"的事项，点击条目可跳转处理：

类别触发条件跳转
安装项目超时未开工 / 跨夜·连续施工忘点完工 / 加班·超预约施工 / 已延期 / 暂停过久施工详情
内部任务待开始且日期已过今天 / 已开始却超时未完工内部任务页
请假待审批，且开始日已到或已过（防漏批导致当天又排了活）请假页
个人日程同工人同天，日程时段与当天项目 / 内部任务时段重叠（冲突）日程页
  • 管理页汇总全员，工人页只显示本人相关。
  • 轮休（周末休息）按约定不计入异常提醒。

👤 账号管理与权限

总经理 / 具备「管理账户」权限者，可在「我的 → 账号管理」中维护团队成员。

账号信息维护

  • 姓名：支持行内直接修改
  • 角色：待分配 / 施工人员 / 店长 / 总经理（决定默认权限集合）
  • 所属门店：绑定门店后仅能查看本门店数据（店长及以上可跨门店）
  • 删除：删除操作不可撤销，需二次确认

分人个性权限（云端）

💡 在角色默认之上单独设置

管理员可对单个非总经理的云端用户单独授予或收回某项能力。未改动的项自动继承该角色的默认权限；改动过的项显示「已单独设置」，实时对全员生效。

权限项覆盖业务全流程，常见包括：

  • 预约类：新建预约、编辑/删除自己的或所有的预约、修改自己项目预约时间/修改所有项目预约时间、修改自己项目预约工时/修改所有项目预约工时（勾选「编辑所有项目」或「编辑自己项目」也自动包含改预约时间/工时）、查看所有门店项目
    ⚠️ 注意：这些预约类权限只在项目开工前有效。项目一旦开始施工或进入终态，预约时间与预约工时即被锁定，任何权限都无法修改，改期请走「延期」流程。
  • 施工类：开始/暂停/恢复/完成施工、填写施工工时与外协工时、分配/移除安装人员、修改完工工时（修改自己项目的完工工时 / 修改所有项目的完工工时——用于终态项目更正填错的施工工时，修改记入操作日志）
  • 人员类：添加/编辑/删除施工人员、查看施工人员
  • 审批类：申请/批准/拒绝请假、验收项目、审核/反审核项目
  • 统计与管理类：查看全局或门店统计、管理门店、管理账户、管理节假日、管理外协、管理工时单价、维修单等
  • 数据工具类（各自独立开关）：导出项目数据 / 工时记录 / 休假记录 / 施工人员 / 门店数据 / 全部数据、数据导入、查看操作日志
  • 个人日程类（各自独立开关）：查看个人日程、查看全员日程、添加日程、编辑自己的日程 / 编辑所有日程、删除自己的日程 / 删除所有日程
  • 内部任务类（各自独立开关）：查看内部任务、下达内部任务、开始内部任务、完成内部任务、编辑内部任务、删除内部任务、审核内部任务

📤 数据导入与导出

「我的 → 数据工具」中的每一项功能，均由对应的独立权限开关控制，可精确授权给需要的成员（无需整体开放）：

数据导出（各自独立权限）

  • 导出项目数据 / 工时记录 / 休假记录 / 施工人员 / 门店数据：分别由对应的导出权限控制，可只放开其中一类
  • 导出全部数据：打包所有业务数据，便于备份或迁移（单独的「导出全部数据」权限）
  • 车辆记录导出 Excel：在车辆页将筛选后的用车记录导出为 Excel
  • 操作日志：由「查看操作日志」权限控制，查看系统关键操作记录，便于审计追溯

数据导入

具备「数据导入」权限的成员，可导入 CSV 文件批量录入数据，支持类型：

  • 项目数据、工时记录、施工人员、门店数据、休假记录、外协人员

导入方式

点击「数据导入」→ 选择文件类型按钮，或直接拖拽 CSV 文件到窗口；系统也可根据文件名（含「工时」「人员」「门店」「请假」「外协」等）自动识别类型

💡 导入结果

导入后界面会显示成功条数与失败条数；部分失败不影响其余记录，可修正后重新导入。

📱 个人中心与系统设置

个人中心（我的）

底部「我的」页汇总个人与团队入口：

  • 功能中心：按权限展示施工人员、外协、请假、个人日程、门店、统计、内部任务、账号管理等
  • 数据工具（管理员/有权限者）：各类导出、操作日志、数据导入、导出全部、帮助与反馈
  • 管理员设置（仅云端总经理）：提醒设置、管理密码设置
  • 登出：云端模式提供退出登录

本地模式与云端模式

  • 本地模式：数据仅存本机，适合单机使用；可添加本地账号
  • 云端模式：数据存于云端，多设备实时同步，支持团队协作与权限分级

💡 实时同步

云端模式下，预约、施工、工时、车辆、权限等变更会通过实时通道推送到其他已登录成员，无需手动刷新即可看到最新数据。

管理密码（云端总经理）

云端总经理可设置管理密码，作为敏感操作（如权限调整）的二次校验；未设置时入口会提示「（未设置）」。

  • 暂停/延期记录包含详细原因
